# wakeup-noads

WakeUp 课程表的非官方精简版本，专注高校教务课表导入与本地课表管理。

## 项目介绍

本项目面向只需要课表核心功能的用户，按官方上游版本逐版检查并精简广告及与课表无关的功能。各版本的功能范围、兼容性和验证结果以对应的 GitHub Release 说明为准。

本仓库包含从官方 APK 生成精简版所用的补丁、构建脚本和测试，不包含官方 APK、第三方构建工具或签名密钥。

本项目由社区独立维护，与 WakeUp 原应用开发者、运营方、广告平台及各高校教务系统不存在隶属、合作或背书关系。

## 功能范围

### 保留功能

- **日程与课表管理**：支持查看、编辑和管理本地课表，切换课表，设置上课时间、周次和学期，并配置课表样式。
- **高校教务导入**：支持浏览高校目录、通过教务系统网页认证，并解析和导入课表；具体兼容范围以各版本发布说明为准。
- **本地数据导入与导出**：支持从本地文件导入课表，并以 ICS 日历格式导出。
- **提醒与桌面组件**：保留本地上课提醒和桌面小组件。
- **设置**：提供课表设置和全局设置；全局设置中显示当前版本号。

主导航仅包含“日程”“课表”“我的”；“我的”页面仅提供“课表设置”和“全局设置”。

### 精简功能

各版本会重新检查下列功能及其入口，并在对应 Release 中说明处理结果：

- 开屏、热启动、插屏、信息流广告及推广入口。
- 学习、搜题和关联助手功能。
- 应用账户、个人资料、会员、收藏及已购课程功能。
- 课表、日历和样式的云同步功能，以及远程皮肤。
- 电脑端扫码及 PC 插件登录入口。
- 自动更新检查、更新提醒、强制更新及 APK 下载入口。
- 分享口令导入、在线分享课表、分享 App 及个人信息导出入口。
- 在线反馈、申请适配、在线教程及模板下载入口。
- 统计、崩溃上报、消息推送及远程运营配置。
- “常见问题”“更多”及其他与课表无关的入口和捆绑功能。

精简功能通过移除入口、停用初始化和限制联网实现；为保持原应用代码兼容，构建中仍可能包含相关第三方 SDK 类。保留类文件不代表对应功能入口仍启用。除高校教务导入所需的请求外，应用的其他联网功能均已停用；学校教务网页自身的内容（包括其中的第三方推广）保持原样，不做拦截或修改。精简云同步和在线分享不影响本地文件导入及 ICS 导出。

## 下载与安装

1. 前往 [GitHub Releases](https://github.com/Lorikein12138/wakeup-noads/releases) 下载正式发布的 APK。
2. 按 Release 提供的校验信息确认文件完整性。
3. 安装前备份课表及其他重要数据，再安装 APK。

应用包名为 `io.github.wakeupnoads`，可与官方 App 同时安装，不会覆盖官方 App，数据也互不共享。早期沿用官方包名 `com.suda.yzune.wakeupschedule` 的版本同样作为独立应用存在。各版本使用同一签名，可直接覆盖升级。系统版本要求以对应 Release 说明为准。
